## Main Features
<a id="main-features"></a>

### Core Functionality
- **MIDI File Support** — Practice your favorite songs by loading any MIDI file, allowing for a personalized learning experience.
- **Hands-Separated Notation** — The program divides the notation for the left and right hands, making it easier to learn each part individually.
- **Tempo Modification** — Adjust the tempo of the songs to match your skill level, helping you gradually increase your speed and proficiency.
- **Note Accuracy Practice** — The software pauses playback when a note is missed, enabling focused practice on challenging sections.
- **Keyboard Compatibility** — While a MIDI controller keyboard is ideal, Synthesia can also be played using your computer's keyboard.

### Advanced Capabilities

- **Performance Tracking** — Monitor your progress and improvement over time, encouraging continued practice and mastery.
